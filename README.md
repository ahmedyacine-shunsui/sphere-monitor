# Sphere Monitor Dashboard

A real-time monitoring dashboard built with React, Vite, and Recharts.

## 📊 Features
- Real-time data simulation
- Interactive charts
- Alert system
- Historical data tracking

## 🛠 Tech Stack
- React
- Vite
- Recharts
- Socket.IO 

## 🚀 Installation

```bash
git clone https://github.com/ahmedyacine-shunsui/sphere-monitor.git
cd sphere-monitor
npm install
npm run dev
